# primes

Count primes in ranges.

Input: the first line has Q (1 <= Q <= 10). Each of the next Q lines has two integers `A B` with
1 <= A <= B <= 2000000000 and B - A <= 100000000.

For each query print one line `C S`: C is how many primes p satisfy A <= p <= B, and S is the sum of
those primes.

## Performance

Besides the tests above, the program is timed on one input at the limits stated here; it must
finish within 60 seconds.
