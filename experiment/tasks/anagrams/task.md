# anagrams

Standard input contains words separated by whitespace (letters only, possibly mixed case). Two words
are anagrams if they have the same letters with the same counts, ignoring case. Group the distinct
words (compare words case-insensitively and print them in lowercase) into anagram groups. Print only
groups with at least 2 words, one group per line, words separated by single spaces and sorted
alphabetically within the group. Order the lines by group size descending, then by the first word of
the group ascending. If there are no such groups print `none`.
