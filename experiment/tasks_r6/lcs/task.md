# lcs

Longest common subsequences of many pairs of strings.

Input: the first line has Q (1 <= Q <= 1000). Then 2Q lines: the two strings of each pair, one per
line, made of lowercase letters a-z, each between 0 and 3000 letters long (an empty string is an
empty line).

For each pair, in order, print one line with the length of the longest common subsequence of its two
strings.

## Performance

Besides the tests above, the program is timed on one input at the limits stated here; it must
finish within 60 seconds.
