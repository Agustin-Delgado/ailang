# knapsack

Solve a 0/1 knapsack problem.

Input: the first line has `N W` (1 <= N <= 3000, 1 <= W <= 2000000). Then N lines `w v`: the weight
and the value of an item (1 <= w <= W, 0 <= v <= 1000000000).

Choose a set of items, each at most once, whose total weight is at most W and whose total value is
as large as possible. Print that total value.

## Performance

Besides the tests above, the program is timed on one input at the limits stated here; it must
finish within 60 seconds.
